# 🦟 DengueEye

**DengueEye** is a full-stack web application designed to support early dengue risk assessment using machine learning. The platform enables users to enter relevant health information, receive a prediction, and access useful insights through a clean and responsive interface.

---

## 📌 Features

- 🤖 Machine Learning-based dengue prediction
- 👤 User authentication and authorization
- 📊 Interactive dashboard
- 📈 Prediction history
- 🔒 Secure login and protected routes
- 📱 Responsive user interface
- ⚡ RESTful API architecture
- 📦 Modular and scalable project structure

## 🚀 Getting Started

### Clone the repository

```bash
git clone https://github.com/sathvikvarma-16/dengueye.git
```

```bash
cd dengueye
```

---

## 📦 Install Dependencies

### Frontend

```bash
npm install
```

### Backend

```bash
cd backend
npm install
```

---

## ▶️ Run the Application

### Start Backend

```bash
cd backend
npm start
```

or

```bash
npm run dev
```

---

### Start Frontend

Open another terminal.

```bash
npm run dev
```

---

Open your browser:

```
http://localhost:5173
```
